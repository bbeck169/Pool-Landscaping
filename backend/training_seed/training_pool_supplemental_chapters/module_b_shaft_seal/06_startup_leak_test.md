# Module B — Shaft Seal · Chapter 6: Start-up, leak test, and burn-in

*Original in-house authorship.*

1. Reopen suction and return valves. Prime the pump per Module C procedure.
2. Restore power at the breaker. Remove lockout.
3. Start the pump. Water should reach the pump within 30–60 seconds.
4. Check the shaft area with a flashlight. Small first-minute weeping is normal as the seal faces bed in. Any steady drip after 5 minutes = seal is not seated correctly. Shut down and re-inspect.
5. Run the pump for 15 minutes at design speed. Recheck. No drip = success.
6. Run through a full turnover cycle. Check again the next day.

**Burn-in expectation.** A well-installed seal will have a hairline of moisture the first hour. That moisture evaporates as the faces polish each other. A single drop per minute after 24 hours = failed installation — usually a chipped ceramic face or contamination on the mating surfaces. Redo the job under warranty.

**Log entry.** Record: pump make/model, motor HP, seal kit part number, install date, first-visit follow-up date, and initial run pressure. This gives you a lifecycle timeline for warranty conversations.
