# Module B — Shaft Seal · Chapter 3: Tools, parts, and pre-work checklist

*Original in-house authorship.*

**Tools.**
- Adjustable wrench + strap wrench (for volute nut)
- 7/16" or 9/16" wrench (for motor mounting bolts, brand-dependent)
- Snap-ring pliers (some seal plates)
- Rubber mallet (never a steel hammer on cast components)
- Impeller-holding tool or a soft-jaw vise
- Silicone lube (Teflon-safe; **never petroleum**)
- Clean rags + a shallow bucket for water discharge

**Parts.**
- Correct seal kit per pump model — record model + HP + shaft type from the motor label BEFORE ordering.
- New volute O-ring (always replace with the seal).
- New diffuser gasket if applicable.

**Pre-work.**
1. Power OFF at breaker. Lock out and tag.
2. Close suction + return valves. Drain volute via drain plug.
3. Note wiring position on the motor terminals (photograph before disconnecting).
4. Verify equipment pad has room to swing the motor free.
