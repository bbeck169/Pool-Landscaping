# Module A — Filter Cleaning · Chapter 4: Cartridge cleaning workflow

*Original in-house authorship. Cartridge OEMs (Pentair, Hayward, Jandy) cited by name + link only.*

## Why cartridge cleaning is a manual procedure

Cartridge filters have no multiport valve and no waste line — the elements are pulled from the housing, rinsed, degreased if needed, and returned. This saves several hundred gallons of water per clean vs sand/DE backwashing, at the cost of tech labor time.

## Tools you need

- Garden hose with adjustable nozzle (fan spray, not needle jet)
- 5-gallon bucket
- Cartridge filter cleaner (TSP-free enzyme + surfactant blend)
- Filter degreaser (for sunscreen / oil residue)
- Muriatic acid (dilute 1:10 for calcium/scale) — full PPE required
- Second bucket for acid dip
- Clean rags

## Step-by-step

1. Pump OFF. Release air-bleed to zero pressure. Open drain plug at bottom of housing and let it drain.
2. Remove clamp band or lock-nut. Lift the housing top (some brands have the elements pinned to the top; check before pulling).
3. Remove elements one at a time. Note orientation for reinstall.
4. Rinse each pleat inside-and-out with the fan-spray hose. Work from top to bottom, moving between pleats systematically. Do not use a pressure washer — the concentrated stream shreds the fabric.
5. If pleats hold oil/sunscreen sheen after rinsing, soak overnight in enzyme degreaser + water per label ratio.
6. If elements show white scale, dip in 1:10 muriatic acid solution for 5–10 minutes with PPE. Rinse thoroughly.
7. Inspect for tears, collapsed pleats, or broken end caps. Replace failed elements — do not reinstall.
8. Reassemble. Lubricate the housing O-ring with Teflon-safe silicone lube; never petroleum grease (destroys O-rings).
9. Pump ON. Note the fresh clean-baseline pressure.

## Rotation practice

Many commercial services keep a second set of pre-cleaned elements at the shop. On visit day, swap sets, take the dirty set back for shop cleaning. Zero pool downtime.

## When to replace vs clean

Replace when pleats show >20% collapse, any tear, any broken end-cap, or when clean-baseline pressure creeps up more than 3–4 psi from install baseline.
