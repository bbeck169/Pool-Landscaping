# Module 3 — Small Engine Repair · Chapter 3: Carburetor cleaning + rebuild

*Original in-house authorship. Consult the OEM parts diagram for your specific model — jets and gaskets are model-specific.*

The single most common small-engine repair. Ethanol-blended fuel dries into a varnish that clogs the microscopic jets inside the carburetor. Symptoms:

- Won't start unless choked.
- Runs but surges (RPM cycles up and down).
- Only runs at full throttle.
- Runs but dies as soon as choke is released.

## Cleaning path (before full rebuild)

1. Pull spark plug wire. Set the engine so the tank won't drain out the fuel line.
2. Drain the carb bowl.
3. Spray aerosol carburetor cleaner into the throat while the engine is off.
4. Reconnect plug wire, start the engine, spray cleaner into the throat while running at high idle (short 2-second bursts, engine will surge).
5. Run 5 minutes. Recheck symptoms.

Cleaning solves 50% of cases. If symptoms remain, full rebuild.

## Rebuild

1. Remove the carburetor from the engine. Note orientation and every linkage before disconnecting.
2. Disassemble on a clean bench. Bowl + main jet + pilot jet + float + needle.
3. Soak metal parts in carb cleaner (dip can, not sprayable) for 15-30 minutes.
4. Blow every passage clear with compressed air. Do NOT ream jets with wire — you'll enlarge them.
5. Install fresh gasket set + fresh needle & seat + fresh main jet if pitted.
6. Reassemble. Reinstall on engine.
7. Adjust idle mixture screws to OEM spec (usually 1-1/2 turns out from lightly-seated as a baseline).

## When to replace the carburetor

If pot metal is corroded through, throttle shaft is worn loose, or you've cleaned + rebuilt twice with recurring issues. Aftermarket replacement carbs run $15-40 online; OEM $50-120. Cost decision easily.
