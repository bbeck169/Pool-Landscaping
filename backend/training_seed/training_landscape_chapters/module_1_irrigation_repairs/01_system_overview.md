# Module 1 — Irrigation Repairs · Chapter 1: The irrigation system as a whole

*Original in-house authorship. Hunter, Rain Bird, Toro cited by name + external OEM manual link only. No verbatim manufacturer content.*

A residential/commercial irrigation system has five layers a tech will interact with:

1. **Point of connection** — usually a copper T off the domestic water line with a backflow preventer.
2. **Mainline** — pressurized PVC (or copper) running from the POC to the valve manifolds.
3. **Valves + wire** — solenoid-driven zone valves grouped in manifold boxes, wired back to the controller.
4. **Lateral lines** — non-pressurized (in most designs) PVC or poly running from each valve to that zone's heads.
5. **Heads + emitters** — the pop-up spray, rotor, or drip emitters that deliver the water.

A "broken sprinkler" call can be a failure in any of the five layers. This module teaches the diagnostic sequence to isolate the failure quickly. The rest of the chapters take each layer in turn.

**Safety upfront.** Any repair on the mainline requires shutting the POC valve, opening the highest downstream drain to relieve pressure, and confirming pressure is zero before cutting. A mainline blowout in a customer's face is a legitimate hospital visit.

**Documentation rule.** Every irrigation repair records: which zone(s), which layer, part number + brand installed, and total gallons/minute the zone was pushing before and after. Second field is optional if you don't have a flow meter, but it's the only way to prove the fix worked to a skeptical customer.
